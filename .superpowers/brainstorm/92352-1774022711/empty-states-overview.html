Empty States & Soft Onboarding — Overview

The app teaches itself through its empty states. No tutorials, no overlays — just a guided path from first launch to first insight.

The Journey

A new user moves through these moments naturally. Each empty state nudges toward the next action.

1

Welcome Screen

First launch only. Sets the tone — paper, typewriter aesthetic, literary warmth. User names their first project and optionally sets a word count goal. One screen, one moment, then they're in.

↓
2

Dashboard — Zero Sessions

The project exists, but no sessions logged. Single blank page on the manuscript stack (already spec'd). Stats show zeroes. Streak is empty. The evocative line + pen FAB hint guide the user to their first session.

↓
3

Project Detail — No Sessions

User taps into their project from the Projects tab. Empty session history area. The stack is the single blank page. Encourages logging from here or from the dashboard.

↓
4

Insights — Progressive Reveal

Three tiers: 0 sessions (fully empty), 1-6 sessions (some stats available, others greyed with "N more sessions" hints), 7+ sessions (everything unlocked). Each tier rewards the user for logging more.

Design Principles

TONE: D (EVOCATIVE + ACTIONABLE)

Lead with a short literary line, follow with a subtle hint. The app has personality but never leaves you stuck.

NO TUTORIALS

No coach marks, no "Step 1 of 4", no tooltip overlays. The empty states are the onboarding.

PAPER METAPHOR THROUGHOUT

Empty states use the same paper/ink/typewriter vocabulary as the rest of the app. Blank pages, not empty containers.

EACH STATE EXITS ITSELF

Every empty state has a clear action that resolves it. No dead ends. The user always knows what to do next.
