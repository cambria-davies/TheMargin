Design Notes

SESSION PAGES AREA

Where overlapping session pages normally stack, a single ruled paper page sits with a typed message. Same paper treatment (grain, ruled lines, red margin, dog ear) as real session pages — the empty state IS a page.

STATS SHOW ZEROES

Total words, session count, progress bar — all present at zero. The structure is visible from the start. No hidden sections or "log sessions to unlock."

COPY TONE

"No sessions yet. This is where your pages will live." — matter-of-fact with a hint of promise. Typed on paper in ink, consistent with how session data will appear.

SELF-RESOLVING

After the first session is logged, the save-to-stack animation plays and real session pages start overlapping here. The empty page is simply replaced — no dismiss logic.
